# Manual de usuario de Inventario Visión

Guía de uso para el personal de la tienda.

## 1. Presentación

Inventario Visión ayuda a llevar el control de las existencias de una tienda. Permite consultar los productos disponibles, registrar ventas, revisar alertas y recibir mercancía con el apoyo de fotografías.

Al analizar una imagen, la aplicación propone los productos y las cantidades que identifica. Esa propuesta no cambia el inventario de inmediato: primero debes compararla con la mercancía recibida, corregir lo necesario y confirmar la entrada.

Este manual acompaña ese recorrido desde el primer acceso hasta el cierre de sesión. También explica las funciones reservadas a quienes administran las cuentas de la tienda.

### Cómo leer esta guía

- Los nombres entre comillas corresponden a opciones, campos o botones de la aplicación.
- Cada procedimiento indica qué hacer y qué resultado comprobar.
- Los ejemplos utilizan cantidades ilustrativas; debes reemplazarlas por las de tu operación.
- Las secciones de administración solo aplican a cuentas con ese permiso.

### Palabras que encontrarás en la aplicación

| Palabra | Qué significa |
|---|---|
| Inventario o existencias | Cantidad registrada de cada producto. |
| Stock | Otra forma de nombrar las existencias. |
| Recepción | Registro de mercancía que llega a la tienda y está por revisar o ya fue procesada. |
| Detección | Resultado del análisis de una fotografía. |
| Movimiento | Operación que suma o resta unidades, como una recepción confirmada, una venta o un ajuste. |
| Umbral de alerta | Nivel de existencias que sirve como referencia para identificar productos con stock bajo. |
| Rol | Conjunto de funciones que una cuenta puede utilizar. |
| Auditoría | Registro de acciones relacionadas con las cuentas y la administración. |

## 2. Antes de comenzar

Para usar la aplicación necesitas:

1. Un teléfono, una tableta o un computador con navegador y conexión a Internet.
2. La dirección web proporcionada por la persona responsable de la tienda.
3. Una cuenta activa.
4. Acceso al correo asociado a tu cuenta para aceptar una invitación o recuperar la contraseña.
5. Una fotografía de la mercancía cuando vayas a utilizar la recepción por imagen.

No necesitas instalar herramientas de desarrollo ni utilizar comandos.

En teléfonos compatibles, la aplicación ofrece la opción de tomar una foto. También permite elegir una imagen guardada en el dispositivo.

### Acceso según el rol

La aplicación distingue dos roles:

| Función | Operador | Administrador |
|---|---|---|
| Consultar el inventario | Sí | Sí |
| Registrar ventas | Sí | Sí |
| Recibir mercancía mediante fotografías | Sí | Sí |
| Revisar y confirmar recepciones disponibles en la aplicación | Sí | Sí |
| Consultar alertas e historial | Sí | Sí |
| Cambiar su nombre y contraseña | Sí | Sí |
| Registrar ajustes de inventario | No | Sí |
| Gestionar usuarios e invitaciones | No | Sí |
| Consultar auditoría de cuentas | No | Sí |

Las opciones disponibles se muestran según el rol de la cuenta. Por ejemplo, la pestaña de movimientos se llama “Ventas” para el rol operador y “Ventas y ajustes” para el rol administrador.

## 3. Crear tu cuenta mediante una invitación

El registro se realiza por invitación. Si todavía no tienes cuenta, solicita el acceso a quien administra la tienda; no necesitas buscar un formulario de registro libre.

### Paso a paso

1. Abre el correo en el que recibiste la invitación.
2. Selecciona el enlace para crear tu cuenta.
3. Espera mientras aparece “Validando invitación”.
4. Comprueba el correo de la cuenta y el rol asignado.
5. Escribe tu nombre.
6. Elige una contraseña de al menos ocho caracteres.
7. Escribe la misma contraseña en “Repite la contraseña”.
8. Pulsa “Crear cuenta”.
9. Cuando aparezca “Cuenta creada”, selecciona “Ir a iniciar sesión”.

Utiliza un nombre que permita reconocer tu actividad en la tienda. La contraseña debe ser personal: no necesitas compartirla con quien envió la invitación.

### Si la invitación no funciona

La aplicación puede mostrar “Invitación no válida” si el enlace está incompleto, venció, ya se utilizó o fue revocado. Solicita una nueva invitación a quien administra la tienda.

Si aparece un problema de conexión, comprueba el acceso a Internet y vuelve a abrir el enlace desde el correo original.

## 4. Iniciar sesión

### Paso a paso

1. Abre la dirección web de Inventario Visión.
2. En “Correo electrónico”, escribe el correo de tu cuenta.
3. En “Contraseña”, escribe tu contraseña.
4. Si necesitas comprobar lo escrito, utiliza el botón con el icono de un ojo.
5. Pulsa “Ingresar”.
6. Espera a que termine el acceso y aparezca la pantalla de inicio.

Antes de mostrar la contraseña, comprueba que nadie más esté mirando la pantalla.

### Si no puedes entrar

Revisa lo siguiente:

- Que hayas utilizado el correo con el que se creó la cuenta.
- Que la contraseña esté completa y no tenga espacios añadidos por accidente.
- Que no esté activado el bloqueo de mayúsculas.
- Que tengas conexión a Internet.

La pantalla incluye un aviso cuando detecta el bloqueo de mayúsculas. Si no recuerdas la contraseña, utiliza “¿Olvidaste tu contraseña?”.

Si la aplicación indica que la cuenta está desactivada, contacta con quien administra la tienda. Cambiar la contraseña no sustituye la activación de la cuenta.

Si aparece un aviso de demasiados intentos, espera el tiempo indicado antes de volver a probar.

## 5. Recuperar la contraseña

Esta opción permite elegir una contraseña nueva mediante un enlace enviado al correo de la cuenta.

### Solicitar el enlace

1. En la pantalla de acceso, selecciona “¿Olvidaste tu contraseña?”.
2. Escribe el correo asociado a tu cuenta.
3. Pulsa “Enviar enlace”.
4. Cuando aparezca “Revisa tu correo”, abre tu bandeja de entrada.
5. Revisa también la carpeta de spam o correo no deseado.
6. Abre el mensaje de recuperación y selecciona su enlace.

Por seguridad, el mensaje de la aplicación no confirma si una dirección pertenece a una cuenta. Si no recuerdas qué correo utilizaste, solicítalo a quien administra la tienda.

### Elegir la contraseña nueva

1. Escribe la contraseña nueva.
2. Repítela en el campo de confirmación.
3. Pulsa “Guardar contraseña”.
4. Espera el mensaje “Contraseña actualizada”.
5. Selecciona “Ir a iniciar sesión”.
6. Ingresa con la contraseña nueva.

El restablecimiento cierra las sesiones anteriores. El enlace solo puede utilizarse una vez. Si aparece “Enlace no válido”, solicita uno nuevo.

No compartas el correo de recuperación ni su enlace.

## 6. Conocer la aplicación

Después de ingresar encontrarás estas secciones:

| Sección | Para qué sirve |
|---|---|
| Inicio | Consultar un resumen de existencias y actividad. |
| Inventario | Buscar productos y revisar sus cantidades y estados. |
| Operaciones | Recibir mercancía, registrar ventas o ajustes y consultar alertas e historial. |
| Perfil | Consultar los datos de tu cuenta y cambiar el nombre o la contraseña. |
| Administración | Gestionar cuentas, invitaciones y auditoría. Solo aparece con ese permiso. |

En pantallas grandes, las secciones aparecen en un menú lateral. En pantallas pequeñas, aparecen como una barra de navegación horizontal.

### Pantalla de inicio

El inicio reúne información para orientar el trabajo: productos por reponer, actividad reciente y accesos a las tareas principales.

Úsalo como un resumen, no como un informe completo. La pantalla muestra hasta cinco productos por reponer y sus consultas de recepciones y movimientos tienen un límite de 100 registros por listado.

El panel no se actualiza automáticamente. Pulsa “Actualizar” cuando necesites consultar de nuevo. Si una actualización falla y se conservan datos anteriores, ten en cuenta el aviso antes de tomar decisiones.

## 7. Consultar el inventario

Esta sección permite conocer las existencias registradas de los productos activos.

### Buscar un producto

1. Selecciona “Inventario”.
2. Localiza el campo “Buscar por nombre”.
3. Escribe parte del nombre del producto.
4. Revisa los resultados.
5. Comprueba el nombre, las unidades disponibles y el estado.

Si no aparece lo que buscas, borra parte del texto y revisa el filtro de estado antes de concluir que el producto no está disponible.

### Utilizar los filtros

Puedes elegir:

- “Todos los estados”.
- “Disponible”.
- “Stock bajo”.
- “Sin stock”.

“Sin stock” corresponde a cero unidades. “Stock bajo” identifica productos con existencias positivas que han llegado a su umbral de alerta o están por debajo. “Disponible” indica que lo superan.

### Entender el resumen

La parte superior muestra:

- Productos activos.
- Unidades disponibles.
- Stock bajo.
- Sin existencias.

“Unidades disponibles” suma cantidades de productos distintos. No representa dinero ni el número de productos diferentes. Además, el contador de stock bajo no incluye los productos sin existencias, que aparecen por separado.

Pulsa “Actualizar” para volver a consultar. Las cantidades se modifican desde las operaciones correspondientes, no escribiendo directamente sobre este listado.

## 8. Recibir mercancía mediante una fotografía

El recorrido completo es:

**Fotografiar → analizar → revisar → corregir → confirmar.**

Analizar una imagen no suma unidades al inventario. La entrada se registra únicamente al confirmar las cantidades.

### 8.1. Preparar la fotografía

Antes de enviarla:

1. Comprueba qué mercancía corresponde a esa recepción.
2. Procura que los productos se distingan con claridad.
3. Evita fotografías oscuras, movidas o con reflejos que oculten los envases.
4. Si una fotografía resulta confusa, toma otra antes de continuar.
5. Ten la mercancía a mano para comparar el resultado.

Estas son orientaciones para facilitar la revisión; no necesitas calcular dimensiones ni modificar ajustes técnicos de la cámara.

El reconocimiento automático puede omitir productos o proponer cantidades incorrectas. Por eso la revisión de la persona que recibe la mercancía forma parte del procedimiento.

### 8.2. Seleccionar y analizar la imagen

1. Entra en “Operaciones”.
2. Abre “Recibir mercancía”.
3. En “Recibir mercancía por foto”, selecciona:
   - “Tomar foto”, para obtener una imagen en un dispositivo compatible.
   - “Elegir de la galería”, para utilizar una imagen guardada.
4. Revisa la vista previa.
5. Si no corresponde, pulsa “Quitar imagen” y elige otra.
6. Pulsa “Analizar recepción”.
7. Espera mientras aparece “Preparando y analizando…”. No vuelvas a enviarla durante el procesamiento.

Al terminar, la aplicación informa que la recepción está pendiente de revisión y que el stock aún no cambió.

### 8.3. Localizar la recepción pendiente

En “Recepciones pendientes”, busca la tarjeta correspondiente a la fotografía.

Cada tarjeta incluye un número de recepción y la fecha. Utiliza esos datos y la imagen para distinguirla de otras recepciones.

No vuelvas a subir la misma foto solo porque todavía no cambió el inventario: primero revisa si ya existe una recepción pendiente.

### 8.4. Revisar las cantidades

1. Compara la fotografía con la mercancía recibida.
2. Revisa cada producto de la tarjeta.
3. En “A confirmar”, escribe la cantidad real que debe entrar.
4. Si un producto no debe sumarse, escribe `0`.
5. No dejes campos vacíos.
6. Utiliza cantidades enteras: no escribas decimales ni números negativos.

Ejemplo: si la aplicación propone cuatro unidades, pero recibiste tres, escribe `3` en “A confirmar”.

El “Resumen de entrada” distingue:

- “Productos con entrada”: productos diferentes cuya cantidad es mayor que cero.
- “Unidades a añadir”: suma de las cantidades que vas a incorporar.

No son el mismo dato: dos productos distintos pueden sumar diez unidades.

### 8.5. Añadir un producto que no fue identificado

Si falta un producto de la mercancía:

1. Busca “Añadir producto omitido” dentro de esa recepción.
2. En “Producto”, selecciona el producto correspondiente.
3. En “Cantidad”, escribe las unidades recibidas.
4. Pulsa “Añadir a la recepción”.
5. Comprueba que aparece con la marca “Añadido manualmente”.
6. Revisa el conjunto de cantidades antes de confirmar.

Añadir un producto a la recepción no crea un producto nuevo en el catálogo ni actualiza todavía las existencias. La entrada sigue pendiente de confirmación.

Si el producto no aparece en el selector, revisa si ya está incluido en la tarjeta. Si no lo está, consulta con quien administra la tienda; no elijas otro producto como sustituto.

### 8.6. Confirmar la entrada

1. Revisa todas las cantidades de la tarjeta.
2. Pulsa “Revisar y confirmar”.
3. En “Confirmar entrada de mercancía”, comprueba los productos y el total de unidades.
4. Si necesitas corregir algo, pulsa “Volver a revisar”.
5. Si todo coincide, pulsa “Confirmar y actualizar stock”.
6. Espera el resultado antes de realizar otra acción.

La aplicación muestra un mensaje cuando la recepción se confirma y el inventario se actualiza. Después puedes comprobar el resultado en “Inventario” y en “Operaciones” → “Historial”.

Ejemplo: si había diez unidades y confirmas una recepción de tres, las existencias pasan a trece, siempre que no haya otros movimientos sobre ese producto.

### 8.7. Descartar una recepción

Utiliza esta opción cuando la propuesta no deba registrarse, por ejemplo, si la fotografía no corresponde a una entrada real.

1. Pulsa “Descartar” en la tarjeta.
2. Revisa la ventana “Descartar recepción”.
3. Si quieres conservarla pendiente, pulsa “Volver a revisar”.
4. Si corresponde descartarla, pulsa “Sí, descartar”.
5. Espera la confirmación.

Descartar retira la propuesta de las pendientes y no modifica el stock.

Si todas las cantidades son cero, no debes confirmar una entrada: descarta la recepción si no corresponde sumar mercancía.

## 9. Registrar una venta

Registra las unidades vendidas para mantener las existencias al día.

### Paso a paso

1. Entra en “Operaciones”.
2. Abre “Ventas” o “Ventas y ajustes”, según tu rol.
3. Busca el producto por nombre.
4. Selecciónalo en la lista.
5. Si puedes elegir el tipo de movimiento, comprueba que esté seleccionada “Venta”.
6. Escribe la cantidad vendida como número entero positivo.
7. Revisa el stock actual y el resultado previsto.
8. Pulsa “Registrar venta” o “Registrar movimiento”, según el botón que aparezca.
9. Espera el mensaje “Movimiento registrado correctamente”.

Ejemplo: para vender dos unidades, escribe `2`, no `-2`. La aplicación realiza la resta.

Si hay ocho unidades y registras dos vendidas, el resultado previsto será seis.

### Si la cantidad supera las existencias

La aplicación no permite registrar un movimiento que deje stock negativo. Revisa el producto, la cantidad y las recepciones pendientes.

No reduzcas la cifra solo para evitar el mensaje. Si el inventario no coincide con la mercancía física, solicita la revisión correspondiente.

## 10. Registrar un ajuste de inventario

Esta función está reservada al rol administrador.

Un ajuste permite corregir diferencias entre las existencias registradas y el conteo físico. No sustituye el registro habitual de ventas o recepciones.

### Paso a paso

1. Entra en “Operaciones” → “Ventas y ajustes”.
2. Busca y selecciona el producto.
3. Elige “Ajuste”.
4. Escribe la diferencia que debes aplicar:
   - Un número positivo suma unidades.
   - Un número negativo resta unidades.
5. Revisa el stock resultante.
6. Pulsa “Registrar movimiento”.
7. Espera la confirmación y comprueba el historial.

La cantidad es la diferencia, no el total final.

| Situación | Ajuste |
|---|---|
| La aplicación indica 10 y el conteo físico es 12 | Escribir `2` |
| La aplicación indica 10 y el conteo físico es 8 | Escribir `-2` |

No se acepta cero ni un resultado negativo de existencias.

## 11. Consultar las alertas

1. Entra en “Operaciones”.
2. Abre “Alertas”.
3. Revisa el producto, el tipo de alerta y la fecha.
4. Consulta sus existencias en “Inventario” para decidir qué mercancía necesita reposición.

Las alertas distinguen “Stock bajo” y “Sin stock”. Son avisos para apoyar la revisión: no registran por sí mismos una compra ni una entrada de mercancía.

Si aparece “Alertas no disponibles”, no lo interpretes como ausencia de alertas. Comprueba los avisos de conexión y vuelve a consultar.

## 12. Revisar el historial de movimientos

1. Entra en “Operaciones”.
2. Selecciona “Historial”.
3. Busca el movimiento por fecha y producto.
4. Compara las columnas “Cambio”, “Antes” y “Después”.

El listado muestra fecha, producto, tipo de movimiento, cambio y existencias anteriores y posteriores. La consulta presenta hasta 100 movimientos; no debe interpretarse como una visualización ilimitada de toda la actividad.

El historial es especialmente útil para comprobar una operación antes de repetirla cuando hubo una demora o una interrupción.

## 13. Gestionar tu perfil

### Consultar los datos de la cuenta

Entra en “Perfil” para consultar nombre, correo y rol.

### Cambiar tu nombre

1. Busca “Cambiar mi nombre”.
2. Escribe el nombre que debe aparecer en la aplicación.
3. Pulsa “Guardar nombre”.
4. Espera “Tu nombre se actualizó correctamente”.

El nombre debe tener entre dos y 120 caracteres. Cambiarlo no modifica el correo ni los permisos.

### Cambiar tu contraseña

1. En “Perfil”, busca “Cambiar contraseña”.
2. Escribe la contraseña actual.
3. Escribe una nueva de al menos ocho caracteres.
4. Repítela en el campo de confirmación.
5. Pulsa “Cambiar contraseña”.
6. Espera el mensaje de actualización.

La nueva debe ser distinta de la actual. Al cambiarla se cierran las otras sesiones, mientras la sesión desde la que realizaste el cambio permanece abierta.

## 14. Administrar el acceso del personal

Esta sección solo está disponible para el rol administrador. Contiene “Usuarios”, “Invitaciones” y “Auditoría”.

### 14.1. Enviar una invitación

1. Entra en “Administración”.
2. Abre “Invitaciones”.
3. En “Invitar a una persona”, escribe su correo.
4. Selecciona el rol.
5. Pulsa “Enviar invitación”.
6. Revisa el correo y el rol en la confirmación.
7. Confirma el envío.
8. Comprueba el mensaje y el historial de invitaciones.

La persona recibe un enlace para elegir su nombre y contraseña. Asigna el rol administrador únicamente a quien deba gestionar accesos y ajustes.

### 14.2. Interpretar los estados de invitación

| Estado | Significado |
|---|---|
| Pendiente | La invitación todavía no se ha utilizado y sigue disponible según su vigencia. |
| Usada | Ya se utilizó para crear una cuenta. |
| Revocada | Se retiró su validez. |
| Vencida | Terminó su plazo de uso. |

Revisa también la fecha de vencimiento. El historial muestra hasta 100 invitaciones; pulsa “Actualizar” para consultar los estados más recientes.

### 14.3. Reenviar una invitación

1. Localiza la invitación.
2. Pulsa “Reenviar”.
3. Comprueba correo y rol.
4. Confirma.

El reenvío genera una invitación nueva e invalida los enlaces anteriores pendientes. Indica a la persona que utilice el mensaje nuevo.

### 14.4. Revocar una invitación

1. Localiza la invitación pendiente.
2. Pulsa “Revocar”.
3. Confirma que corresponde retirar ese acceso.

El enlace revocado ya no permite crear una cuenta. Revocar una invitación no sustituye la desactivación de una cuenta que ya fue creada.

### 14.5. Cambiar un rol

1. Abre “Usuarios”.
2. Localiza la cuenta por nombre y correo.
3. Cambia el campo “Rol”.
4. Revisa el mensaje de confirmación.
5. Confirma si corresponde.

Comprueba la identidad antes de aceptar. La aplicación no permite modificar tu propio rol desde ese panel.

### 14.6. Desactivar o activar una cuenta

Para retirar el acceso:

1. Localiza la cuenta en “Usuarios”.
2. Pulsa “Desactivar”.
3. Revisa nombre y correo.
4. Confirma.

La desactivación retira el acceso e invalida las sesiones. La cuenta no se elimina, para conservar su historial.

Para devolver el acceso, localiza la cuenta desactivada y utiliza “Activar”. No puedes desactivar tu propia cuenta desde este panel.

### 14.7. Consultar la auditoría

1. Abre “Auditoría”.
2. Revisa fecha, responsable, acción y detalle.
3. Utiliza “Actualizar” cuando necesites una consulta reciente.

Este apartado muestra los últimos 100 eventos administrativos y de cuentas. Para ventas, ajustes y recepciones, utiliza “Operaciones” → “Historial”. Son registros distintos.

## 15. Cambiar la apariencia y cerrar sesión

### Elegir el tema

En la cabecera puedes seleccionar:

- “Claro”.
- “Oscuro”.
- “Sistema”.

Elige la apariencia que facilite la lectura. Esta opción no modifica los productos ni las cantidades.

### Cerrar sesión

1. Espera a que termine cualquier operación en curso.
2. Comprueba su resultado.
3. Pulsa “Cerrar sesión”.
4. Verifica que aparezca la pantalla de acceso.

En dispositivos compartidos, cierra la sesión al terminar.

## 16. Resolver situaciones habituales

| Situación | Qué hacer |
|---|---|
| No puedes iniciar sesión | Revisa correo, contraseña y mayúsculas. Si no recuerdas la contraseña, utiliza recuperación. |
| No llega un correo | Revisa spam, comprueba el correo utilizado y evita solicitar muchos mensajes seguidos. Si persiste, contacta con quien administra la tienda. |
| El enlace de recuperación no funciona | Solicita uno nuevo y ábrelo desde el mensaje recibido. |
| La invitación no es válida | Solicita una nueva invitación. Si ya creaste la cuenta, intenta iniciar sesión. |
| La foto no se procesa | Lee el mensaje. Si hay conexión, prueba otra fotografía o una imagen de la galería. |
| No se identifican productos | Revisa la foto y añade manualmente los productos disponibles que correspondan, o descarta la propuesta si no debe registrarse. |
| Falta un producto en la recepción | Utiliza “Añadir producto omitido”. |
| No aparece un producto en el selector | Comprueba si ya está incluido. Si no lo está, consulta con administración. |
| No puedes confirmar | Revisa que no haya campos vacíos, decimales o negativos y que al menos una cantidad sea mayor que cero. |
| La venta dejaría stock negativo | Comprueba producto, unidades y recepciones pendientes; solicita revisión si existe una diferencia. |
| No aparece “Administración” | Esa sección depende del rol de la cuenta. |
| Los datos parecen antiguos | Pulsa “Actualizar” y comprueba si aparece algún error. |
| No sabes si una operación terminó | Consulta primero el estado, las existencias o el historial antes de repetirla. |

Los mensajes y las comprobaciones de acceso, recuperación y operaciones orientan estos pasos; el panel de inicio también advierte cuando conserva datos de una consulta anterior.

## 17. Recorrido recomendado para el trabajo diario

### Al comenzar

1. Inicia sesión con tu propia cuenta.
2. Revisa “Inicio”.
3. Actualiza la información.
4. Consulta los productos por reponer.
5. Comprueba si tienes recepciones pendientes.

### Al recibir mercancía

1. Toma o selecciona una fotografía.
2. Analízala.
3. Compara la propuesta con la mercancía.
4. Corrige cantidades y añade productos omitidos.
5. Revisa el resumen.
6. Confirma una sola vez.
7. Comprueba el resultado.

### Al registrar una venta

1. Selecciona el producto.
2. Escribe las unidades vendidas.
3. Revisa las existencias previstas.
4. Registra la operación.
5. Espera la confirmación.

### Al terminar

1. Comprueba que las operaciones realizadas tengan resultado.
2. Revisa el historial si hay dudas.
3. Comunica cualquier diferencia que no puedas resolver.
4. Cierra sesión.

La regla principal de uso es sencilla: la aplicación ayuda a reconocer y registrar, pero la decisión de qué mercancía entra y en qué cantidad debe basarse en tu revisión. Una fotografía analizada es una propuesta; una recepción confirmada es una entrada registrada.
